Lingerie Customizer v2.19.4｜スマホ配置カスタマイズ版

主な変更
1. よく使う設定：全100基本項目から追加、削除、上下移動。
2. 詳細設定：9カテゴリの順序と、それぞれのカテゴリ内の項目順を独立編集。
3. アプリ全体：よく使う設定・色見本・紹介ポーズ・任意スタイル指定を含む17セクションを上下移動。
4. 自動保存：画面配置を従来の設定保存と同じブラウザ内に保存。既存の設定JSONへの同梱と配置だけのJSON出力・読込に対応。
5. よく使う設定は前版の14項目を初期配置とし、選択後も詳細カテゴリを開いたままにする仕様を維持。
6. ブラ・ショーツ・紹介ポーズ123種類・固定/除外/出現率・人物別・優先順位など抽選エンジンは維持。

使い方
「画面のカスタマイズ」→「編集する」で各一覧の ↑ ↓ を操作。× でよく使う項目から外す。
「配置だけJSON保存」で配置のみをバックアップ。「設定をJSON保存」でも配置が含まれる。
配置を初期化しても、抽選済みの値と固定はそのまま。

GitHub Pagesへの更新
ZIP内のindex.html、sw.js、manifest.webmanifestを既存ファイルと同じ場所に上書き。
既存のicon-192.png、icon-512.pngはそのまま残す。更新前に設定JSONをバックアップする。

検証内容: JavaScript構文検査、Chromiumでの主要UI操作、リロード時の保存・旧形式JSON互換。
Safari実機は未検証。ブラウザの保存領域が消去された場合は配置JSONから復元してください。
