Lingerie Customizer v2.10.0 / GitHub Pages update

同梱ファイル:
- index.html: アプリ本体（監査済み94候補追加）
- sw.js: Service Worker（v2.10.0キャッシュ）

更新方法:
1. GitHub Pagesで公開しているリポジトリの同名ファイル3つを上書き。
2. 既存の icon-192.png と icon-512.png はそのまま残してください（本ZIPには含めていません）。
3. Safariで公開ページを開き、再読み込みしてください。古い表示が続く場合はページを再度開き直してください。

変更点:
- 129案を最終仕分けしたデータに従い、94候補を追加（87通常追加＋7項目移動追加）。
- 顔の方向性は従来24種類＋ボーイッシュ系の25種類。可愛い・美人・その他の有効グループを均等抽選。
- 各グループ内は既存の出現率倍率を維持。固定と除外設定を優先。
- メイクは17＋13＝30表記。ピンク系／モード系は既存データ互換のため表示を保持し、通常の新規ランダム抽選は各々の同義候補を除外（有効系統28）。
- 新しいセクシー度は設けず、人物と衣装の偶然の組み合わせを維持。

検証範囲:
- HTML内JavaScript構文チェック、Chromium内でのロード、94候補の登録、抽選・プロンプト生成、3人スナップショット、顔9,000回サンプルの割合、除外・固定の基本確認。
- GitHub Pages/Safari実機、全候補の視覚的再現、全組み合わせ検証は未実施。
