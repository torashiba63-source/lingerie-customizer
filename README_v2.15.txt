Lingerie Customizer v2.15.0 — 条件付きランダム抽選 修正版

更新するファイル:
  index.html
  sw.js
  manifest.webmanifest

GitHub Pages の同じ場所に上記3ファイルを上書きしてください。
既存の icon-192.png / icon-512.png は削除しないでください。
設定を残したい場合は更新前にアプリから設定JSONを書き出してください。

主な変更:
・寝そべる・座る・立つを区別し、ソファに寝そべるポーズを着席扱いしない
・集合姿勢を、既存ポーズに適合する候補から重み付き抽選
・家具を、姿勢に必要な座面と矛盾しない候補から重み付き抽選
・固定（手動選択）の相互衝突は警告し、固定を勝手に変更しない
・小物なしの場合は手持ち・卓上の配置指示を抑制
・v2.13があとからポーズを調整した場合も撮影ディレクションを再同期
・従来の顔、色、衣装、人物別設定、確率・除外ルールを保持

検査: HTML内のJavaScript構文をNode.jsで検査済み。
注意: Safari実機・実画像生成は未検証。以前のプロンプト整形エンジンにも出力が残るため、
すべての複合条件で矛盾ゼロを保証するものではありません。
