Lingerie Customizer v2.15.1 — 仕事動作連動型撮影ディレクション

更新するファイル: index.html / sw.js / manifest.webmanifest
GitHub Pagesの既存ファイルを上書きしてください。既存のicon-192.png / icon-512.pngを削除しないでください。

仕様:
・最初に既存の「仕事中の動作」を抽選（既存の候補・重み・除外・固定を維持）。
・「記者撮影に対応」「撮影用に立つ」「プレス撮影に応じる」等の撮影系仕事が選ばれた場合だけ撮影ディレクション抽選に進む。
・複数人で一人でも撮影系の仕事が割り当てられた場合は撮影ディレクションを有効化する。
・通常の接客・商品説明・展示準備等の仕事では撮影ディレクションの章をプロンプトへ追加しない。
・撮影目的・集合姿勢・家具・小物・背景の既存候補・除外・重み・手動指定は維持。
・50:50の独立した最上位抽選は設けない。既存の仕事動作候補における実際の撮影確率は候補の重みと除外に依存する。

注意: Safari実機・画像生成AIの実出力は未確認。既存のv2.13姿勢・業務調整やv2.9.10整形は維持。
