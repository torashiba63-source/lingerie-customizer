Lingerie Customizer v2.13.0 — 仕事・ポーズ・設備の整合性エンジン（初期実装）

【更新ファイル】
index.html / sw.js / manifest.webmanifest
旧アイコン icon-192.png / icon-512.png は削除しないでください。

【主な変更】
1. 既存の紹介ポーズ（98候補）と既存の仕事・動作フェーズを保持。
2. 仕事中・静止説明中では手・ポーズ・仕事・身体方向の順に、非固定かつ除外されていない候補内で矛盾を解消。出現率1〜5倍を考慮。
3. 記者・プレス撮影は撮影中でもモデルポーズ許容。仕事が「撮影用に立つ」のときは座る・寝る姿勢と矛盾扱い。
4. 作業後は、手持ち小物を置く／無理のない保持をする解釈をプロンプトに追加。
5. ソファ・チェア・マット・足置き台など必要設備を、既存の会場設定を直接書き換えずプロンプトに追記。
6. 固定条件などで解消できない場合、元の値は保持し「要確認」を表示。
7. 2〜3人の場合はグループの人物別仕事内容・姿勢も検査。既存の衣装差異ロジックは保持。
8. 詳細構想、画像生成用、短縮版へ v2.13 の整合性情報を追記。

【適用範囲と限界】
・これは整合性改善の初期実装であり、自然な写真になることを保証するものではありません。
・設定欄の全項目再抽選そのものは元の抽選エンジンを維持し、構想生成・比較案生成時の完成スナップショットに対して調整します。
・設備はプロンプトの補助指示です。会場や設備の元の選択値を変更するものではありません。
・固定された場所・ブースで設置可否が判断できない場合は警告します。
・一部人物別デザイン抽選の出現率適用など、既存エンジン側の未解決事項は今版で全面刷新していません。
・Safari、GitHub Pagesの実機動作および画像生成の再現性は未検証です。

【検証】
・HTML内24個のJavaScriptについて node --check: 全件合格
・Node単体試験: 非固定姿勢の修復、固定ポーズ時の業務変更、双方固定時の警告、ソファ補完、作業後の制限解除を確認
・Chromium実ファイルのアクセスは実行環境がブロック（net::ERR_BLOCKED_BY_ADMINISTRATOR）。画面検証は未完了

【更新方法】
1. 旧版の設定を「設定をJSON保存」でバックアップ
2. GitHub Pages リポジトリの index.html / sw.js / manifest.webmanifest をこのZIPのファイルで上書き
3. アイコン２種類は削除しない
4. Safariで再読み込み。旧画面が出る場合はいったんタブを閉じて開き直す
